# Session 16 — DPO study plan

**Status:** This directory contains a study plan only. It has no DPO trainer,
dataset, training script, comparison script, or results. The
[theory note](../../notes/md/note_16_dpo_and_variants.md) contains the
derivation and conceptual discussion.

## Intended exercise

Implement a small preference-training experiment with explicit train and
evaluation splits. Record the model and reference revisions, dataset
provenance, random seed, dependency versions, `beta`, and evaluation method.
Compare against a PPO baseline only if both methods use a matched dataset,
compute budget, and evaluation protocol.

A completed exercise would include:

1. A preference dataset with documented provenance and permitted use.
2. A DPO objective with a unit test against a small hand-computed example.
3. A runnable training entry point and a tiny smoke configuration.
4. A separate evaluation set and a result table generated by code.

No empirical DPO-versus-PPO result is claimed by this repository. For the
implemented toy PPO-RLHF pipeline, see
[Session 15](../15_rlhf_basics/README.md).
